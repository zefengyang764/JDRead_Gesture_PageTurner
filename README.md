# JDRead Gesture Page Turner

这是一个用于浏览器网页阅读场景的 Python 手势翻页工具。程序通过摄像头和
MediaPipe Hands 识别单手横向挥动，并使用 PyAutoGUI 模拟键盘方向键。

- 实际向左挥手：按下键盘右方向键，进入下一页
- 实际向右挥手：按下键盘左方向键，返回上一页
- 按 `Q`：退出程序

## 安装方法

1. 安装 Python 3.10 或 3.11，并在安装时勾选将 Python 添加到 `PATH`。
2. 打开命令提示符或 PowerShell，进入项目目录：

   ```powershell
   cd JDRead_Gesture_PageTurner
   ```

3. 建议创建虚拟环境并安装依赖：

   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

## 使用方法

1. 用户自行打开浏览器，登录京东读书账号，并进入需要阅读的页面。
2. 双击 `run.bat`，或在项目目录运行：

   ```powershell
   .\.venv\Scripts\python.exe main.py
   ```

3. 摄像头预览窗口出现后，将手放在摄像头前。
4. 让浏览器阅读页面保持为当前活动窗口，否则方向键可能发送到其他窗口。
5. 向左挥手进入下一页，向右挥手返回上一页。
6. 在摄像头预览窗口中按 `Q`，或关闭预览窗口退出。

程序默认使用编号为 `0` 的摄像头，挥手识别阈值为 80 像素，触发冷却时间为
1 秒。

## 常见问题

### 摄像头无法打开

- 检查摄像头是否已连接。
- 在 Windows 隐私设置中允许桌面应用访问摄像头。
- 关闭正在独占摄像头的会议或录像软件。
- 如果需要使用其他摄像头，可修改 `main.py` 中的 `CAMERA_INDEX`。

### 挥手没有触发翻页

- 确保光线充足，并让完整手掌出现在画面中。
- 挥手的横向位移需要超过 80 像素。
- 确保浏览器阅读页面是当前活动窗口。
- 某些阅读页面可能使用不同快捷键，可按页面实际快捷键修改
  `pyautogui.press("right")` 和 `pyautogui.press("left")`。

### 一次挥手触发过于频繁

程序已设置 1 秒冷却时间。可以修改 `main.py` 中的
`COOLDOWN_SECONDS` 调整间隔。

### 依赖安装失败

建议使用 Python 3.10 或 3.11，并先升级 pip：

```powershell
py -3.11 -m pip install --upgrade pip
py -3.11 -m pip install -r requirements.txt
```
